# What to Check in Render Dashboard

## You say it's "not working" - let's diagnose exactly what's wrong

## Step 1: Check Render Logs

1. Go to your Render Dashboard
2. Click on your **YTDownloader** service
3. Click **Logs** tab in the left sidebar

Look for these key messages:

### During Build/Deploy:

✅ **Good signs:**
```
📦 Installing Node dependencies...
✓ npm install completed
🎬 Installing/Updating yt-dlp...
✓ yt-dlp version: 2024.11.04 (or newer)
=== Build Complete ===
```

❌ **Bad signs:**
```
ERROR: Could not install yt-dlp
pip install failed
```

### During Startup:

✅ **Good signs:**
```
YouTube Downloader Backend running at http://localhost:5000
```

Check for cookie messages (you might need to trigger an API call first)

### During API Requests:

❌ **If you see these - cookies are missing/wrong:**
```
WARNING: [youtube] hoetQkfa6wY: Unable to download API page: HTTP Error 403
ERROR: [youtube] hoetQkfa6wY: Failed to extract any player response
```

✅ **Good signs:**
```
[youtube] jNQXAC9IVRw: Downloading webpage
[youtube] jNQXAC9IVRw: Downloading ios player API JSON
```

In Render Dashboard:
1. Go to **Environment** tab
2. Find `YOUTUBE_COOKIES`
3. Click **Edit** (pencil icon)

**What you should see:**

## Step 4: Common Issues and Fixes

### Issue 1: "Service keeps sleeping"
**Symptom:** First request is very slow (30+ seconds)
**Cause:** Render free tier sleeps after 15min inactivity
**Fix:** Normal behavior. Consider upgrading to Starter ($7/mo) for always-on

### Issue 2: "Getting 403 Forbidden"
**Symptom:** API returns `HTTP Error 403: Forbidden`
**Cause:** Cookies missing, incomplete, or expired
**Fix:** 
```powershell
.\verify-cookies-format.ps1
# Copy to Render, save, redeploy
```

### Issue 3: "Getting 503 Service Unavailable"
**Symptom:** Can't reach the service at all
**Cause:** Build failed or service crashed
**Fix:** Check Render logs for build errors

### Issue 4: "yt-dlp version too old"
**Symptom:** Still getting extraction errors with cookies
**Cause:** Old yt-dlp version on Render
**Fix:** Redeploy (this runs build script which updates yt-dlp)

### Issue 5: "Works sometimes but not always"
**Symptom:** Intermittent 403 or 429 errors
**Cause:** YouTube rate limiting or cookies expiring
**Fix:** 
- For rate limiting: Wait 10-15 minutes
- For expiring cookies: Export fresh cookies

## Step 5: Systematic Diagnosis

### A. Does it work locally?

```powershell
# If you have cookies.txt:
npm start

# Test in another terminal:
curl -X POST "http://localhost:5000/api/info" `
  -H "Content-Type: application/json" `
  -d '{"url":"https://www.youtube.com/watch?v=jNQXAC9IVRw"}'
```

**If YES:** Problem is with Render deployment (environment variable or build)
**If NO:** Problem is with cookies themselves

### B. Are cookies complete?

```powershell
.\verify-cookies-format.ps1
```

**If ERRORS:** Export fresh cookies
**If WARNINGS:** Might work but could fail - consider fresh export
**If GOOD:** Cookies should work on Render

### C. Is Render environment variable correct?

1. Open cookies.txt in Notepad
2. Count lines (should be 10-50)
3. Compare with Render environment variable
4. They should be IDENTICAL

### D. Did Render redeploy after saving?

After changing environment variables:
1. Check **Events** tab in Render
2. Should show "Deploy triggered by..."
3. Wait 2-3 minutes
4. Status should be "Live"

## Step 6: The Nuclear Option

If nothing works, start fresh:

1. **Delete YOUTUBE_COOKIES** from Render environment
2. **Save** (triggers redeploy)
3. **Export fresh cookies** locally:
   ```powershell
   .\setup-cookies.ps1
   ```
4. **Verify cookies**:
   ```powershell
   .\verify-cookies-format.ps1
   ```
5. **Test locally first**:
   ```powershell
   npm start
   # Test in browser or curl
   ```
6. If local works, **copy to clipboard**:
   ```powershell
   .\verify-cookies-format.ps1
   # Type 'y' when asked to copy
   ```
7. **Add back to Render**:
   - Environment → Add Environment Variable
   - Key: `YOUTUBE_COOKIES`
   - Value: Paste (Ctrl+V)
   - Save
8. **Wait for deploy** (2-3 minutes)
9. **Test Render**:
   ```powershell
   .\test-render-deployment.ps1
   ```

## Quick Checklist

Before asking for help, verify:

- [ ] cookies.txt exists locally
- [ ] Run `.\verify-cookies-format.ps1` - shows no errors
- [ ] Cookies work locally (tested with npm start)
- [ ] YOUTUBE_COOKIES added to Render environment
- [ ] Variable value has 10+ lines (not just 2-3 comment lines)
- [ ] Saved changes in Render
- [ ] Redeploy completed (check Events tab)
- [ ] Waited 2-3 minutes after deploy
- [ ] Tested with `.\test-render-deployment.ps1`
- [ ] Checked Render logs for specific errors

## Most Likely Issues (in order of probability):

1. **60%** - YOUTUBE_COOKIES is incomplete (only headers, no actual cookies)
2. **20%** - Cookies are expired or from logged-out session
3. **10%** - Render didn't redeploy after saving environment variable
4. **5%** - yt-dlp is outdated on Render (need to redeploy)
5. **5%** - Other (rate limiting, YouTube temporary block, etc.)

**Run the diagnostic script to find out which one:** `.\test-render-deployment.ps1`
